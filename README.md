An entry for the make.fun contest "The Router Confesses" — one line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes exactly one line to `/output/entry.txt`: the router, ignored in the corner for years, finally seizing its moment to be the plot twist.
